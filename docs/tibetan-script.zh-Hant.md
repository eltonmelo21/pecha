# 藏文

這個技能（skill）製作的藏式長條經書（pecha）以藏文書寫，字型為 Noto Serif Tibetan。本頁整理目前對這套文字來源的認識，將傳統的說法與學術研究的討論分開，並列出字母表及其轉寫。每一項陳述都註明出處，文末列有參考文獻。

## 傳統的說法

- 藏文史書將這套文字歸功於吞彌·桑布扎（Thonmi Sambhota），他是七世紀松贊干布（Songtsen Gampo）皇帝的大臣（Chhosphel 2010；van Schaik 2011，pp. 49–50）。
- 據傳說，皇帝在他年輕時派他前往印度。在那裡，一位婆羅門教他二十種文字，他回國後依此創製了藏文字母（van Schaik 2011，pp. 49–50）。
- 他也被認為著有數部文法論著，其中兩部至今仍是藏文文法規則的根本典籍（Chhosphel 2010）。
- 這個說法目前已知最早的來源，是一部伏藏文本 *Pillar Testament* 與一部氏族史《巴協》（*Testament of Ba*；van Schaik 2011，p. 49）。

## 學術研究的討論

- 沒有任何留存的文獻能確定追溯到吞彌·桑布扎，他是否真有其人也曾受到質疑，質疑者之中也包括藏族學者（van Schaik 2011，pp. 51–52）。
- 比較字母的形狀後，van Schaik 認為北印度與尼泊爾的晚期笈多文字最可能是其範本。他排除了喀什米爾、于闐與中亞的文字，並認為苯教傳統的象雄文字很可能要到十世紀以後才出現（van Schaik 2011，pp. 60–67, 75）。
- 這套文字很可能在松贊干布時期成形，並在 630 年代或 640 年代定型，略早於 654–655 年法律成文之時，如 Old Tibetan Annals 所記載（van Schaik 2011，pp. 52–53, 75–76）。
- 現存最古老、有年代可考的藏文碑銘，是拉薩的恩蘭·達札路恭紀功碑（Zhol pillar），約立於 767 年（van Schaik 2011，pp. 51, 56–57）。

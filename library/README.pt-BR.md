# Biblioteca de Pechas

Read this page in [English](README.md) · [繁體中文](README.zh-Hant.md)

Pechas geradas por esta skill, prontas para baixar e imprimir. A biblioteca cresce aos poucos, com sūtras, dhāraṇīs, preces, louvores, aspirações e práticas, em estilos variados.

> [!IMPORTANT]
> Esta biblioteca reúne 108 pechas de textos que não pedem transmissão nem iniciação. Isso só é possível pela generosidade da Lotsawa House, que publica estes textos abertos, sem restrição, sob a licença Creative Commons CC BY-NC 4.0.

Cada linha traz dois PDFs na segunda coluna: Uma face, para imprimir só de um lado da folha, e Frente e verso, a mesma pecha preparada para os dois lados. Como imprimir cada uma está em [Como Imprimir as Pechas](../docs/impressao.md).

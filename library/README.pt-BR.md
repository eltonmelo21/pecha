# Biblioteca de Pechas

Read this page in [English](README.md).

Pechas geradas por esta skill, prontas para baixar e imprimir. A biblioteca cresce aos poucos, com sūtras, dhāraṇīs, preces, louvores, aspirações e práticas, em estilos variados.

> [!IMPORTANT]
> As pechas desta biblioteca são de textos que não pedem transmissão nem iniciação. Isso só é possível pela generosidade da Lotsawa House, que disponibiliza estes textos sob a licença CC BY-NC 4.0.

# Pecha Library

Leia esta página em [português](README.pt-BR.md).

Pechas made by this skill, ready to download and print. The library grows little by little, with sūtras, dhāraṇīs, prayers, praises, aspirations and practices, in varied styles.

> [!IMPORTANT]
> The pechas in this library are of texts that do not require transmission or empowerment. This is only possible thanks to the generosity of Lotsawa House, which makes these texts available under the CC BY-NC 4.0 licence.

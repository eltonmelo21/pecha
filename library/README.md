# Pecha Library

Leia esta página em [português](README.pt-BR.md).

Pechas made by this skill, ready to download and print. The library grows little by little, with sūtras, dhāraṇīs, prayers, praises, aspirations and practices, in varied styles.

> [!IMPORTANT]
> This library brings together 108 pechas of texts that do not require transmission or empowerment. This is only possible thanks to the generosity of Lotsawa House, which publishes these texts openly, without restriction, under the Creative Commons CC BY-NC 4.0 licence.

The title link opens the single-sided pecha. The link in the Double-sided column opens the same pecha prepared for both sides of the sheet. How to print each one is in [How to Print the Pechas](../docs/printing.md).

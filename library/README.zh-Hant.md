# Pecha 文庫

[English](README.md) · [Português](README.pt-BR.md) · **繁體中文**

> [!NOTE]
> 本頁中文版在人工智慧的協助下翻譯，希望方便華人佛教修行者閱讀。譯文尚未經熟悉佛法的中文譯者審閱，難免有疏漏之處，若有錯誤，敬請見諒；日後的版本將繼續校訂改進。🙏

這裡收錄以本技能（skill）製作的藏式長條經書（pecha），可直接下載列印。文庫將逐步擴充，收錄經、陀羅尼、祈請文、讚、祈願文與修法，風格多樣。

> [!IMPORTANT]
> 本文庫匯集 108 部 pecha，所收文本皆無須口傳或灌頂。這全賴 Lotsawa House 的慷慨：他們以 Creative Commons CC BY-NC 4.0 授權公開發布這些文本，不設限制。

每一列的第二欄附有兩個 PDF：「單面列印」適合只印在紙張的一面；「雙面列印」則是同一部 pecha 為正反兩面列印而編排的版本。各版本的列印方式，請見〈[如何列印 pecha](../docs/printing.zh-Hant.md)〉。
